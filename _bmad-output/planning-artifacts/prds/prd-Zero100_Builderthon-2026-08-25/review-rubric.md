## 리뷰에서 처리한 조정

- 기존 사용자 여정 ID를 `UF-1~UF-3`로 정리하고, 각 흐름에 가상의 주인공을 명시했다. 이는 실제 사용자 조사로 검증된 페르소나를 의미하지 않는다.
- 이전의 질문 후보 임시 기본값 3개를 제거하고 정확한 개수를 `D-01`로 유보했다.
- 발표용 입력 데이터의 형식·수량·실시간/사전 처리 방식을 `D-02`로 유보하되, UX·아키텍처·구현 진입 전 `PB-01`에서 확정하도록 했다.
- ChatGPT 모델·버전과 베이스라인 비교 조건을 `D-03`으로 유보하고 `PB-02`의 재현 계약으로 연결했다.
- 문제 카드 숫자·출처와 레포·배포 링크는 PRD를 막지 않는 제출 단계 deferred item으로 분리했다.

## 남은 리스크

- 발표 데이터 계약이 늦어지면 PDF 좌표 처리 범위와 데모 신뢰성 판단도 늦어진다.
- 베이스라인을 비교 컷 제작 직전에 호출하면 응답 재현성이 낮아질 수 있으므로 출력 보존을 PB-02의 필수 조건으로 둔다.
- 질문 후보의 개수가 유보된 동안에도 질문 이유·연결 기준·참조 근거·사람의 선택 절차는 변경하지 않는다.
