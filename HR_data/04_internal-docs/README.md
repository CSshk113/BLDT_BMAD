## 판정 체계 핵심 (요약)

**서류 판단은 성격이 다른 두 번**에 걸쳐 이뤄집니다.

- **1단 — HR 스크리닝**: 접수 직후 **HR 담당자 1명**이 전량을 훑습니다.
  묻는 질문은 *"이 서류를 리더에게 넘길 가치가 있는가"* 입니다.
  불합격 사유는 **3종**이며 **복수 선택이 가능**합니다:
  `불합격 - 허수 지원` / `불합격 - 경력/역량 부족` / `불합격 - 회사/지원자 FIT`
  (통과는 `스크리닝 통과`. **이 단계에 `기타` 는 없습니다.**)

- **2단 — HM 서류 심사**: 1단 통과분만 **하이어링 매니저**가 이력서 전문과 JD를 대조합니다.
  묻는 질문은 *"이 사람을 만나 볼 가치가 있는가"* 입니다.
  근거는 `서류 전형` **8분류**(합격 4 + 불합격 4), 결론은 `서류심사` 단일 값입니다.

- 이후 **GP 역량 평가**(합·불 아님, 면접 참고 자료) → **1차 면접**(HR+HM) →
  **레퍼런스 체크 또는 커피챗** → **2차 면접**(임원) → **처우 협의** → 최종.

> 각 값의 정의와 "어떤 이력서를 보면 그 판정을 내리는가"는
> `03_스크리닝판정기준/서류_판정_기준.md` 가 정본입니다.

### 표기 규칙 — 문자열을 그대로 맞춰야 합니다

- 판정 문자열의 구분자는 **슬래시**입니다: `경력/역량 부족`, `회사/지원자 FIT` (가운뎃점 아님)
- 괄호 앞에 **공백이 있습니다**: `합격 (비대면)`
- 단계 문자열은 띄어쓰기까지 정확히: `GP 역량 평가 진행`, `레퍼런스체크 진행`
