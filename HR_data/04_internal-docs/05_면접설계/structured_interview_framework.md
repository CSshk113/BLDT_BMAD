# 구조화 면접 프레임워크 (범용 버전)

## 목적
해당 포지션에서 실제로 성과를 낼 수 있는 사람을 선별하기 위한 경험 기반(Behavioral) 면접

→ 특정 직무(운영, 개발, 영업 등)에 한정되지 않고  
→ 모든 포지션에 적용 가능한 범용 구조를 기반으로 설계

---

## 1. 기본 원칙

### 1) 경험 기반 인터뷰 (Behavioral Interview)
- 모든 질문은 실제 경험을 기반으로 한다
- “어떻게 생각하나요?” 보다 “실제로 어떻게 했나요?”를 묻는다

### 2) 실행 검증 중심
- 단순 지식이 아니라 실행 경험을 검증
- 말이 아니라 결과와 과정 확인

### 3) 재현 가능성 검증
- 해당 사람이 다른 환경에서도 동일하게 수행할 수 있는지 확인

---

## 2. 범용 구조 (All Roles)

### [Part 1] 경험 기반 핵심 역량 검증
- 지원자의 주요 경험
- 문제 해결 방식
- 판단 기준

### [Part 2] 협업 및 태도
- 커뮤니케이션
- 책임감
- 팀워크

### [Part 3] 성장 가능성
- 학습 방식
- 피드백 수용
- 개선 경험

### [Part 4] 지원자 질문
- 문제 인식 수준
- 관심도
- 방향성

---

## 3. 커스터마이징 구조 (JD & 팀 기반)

이 프레임워크는 아래 2가지 요소를 추가하여 포지션별로 커스터마이징한다.

### 1) JD 기반 커스터마이징

- 핵심 책임 정의
- 요구 역량
- 성과 기준

→ 각 포지션별로 질문의 깊이와 방향을 조정

---

### 2) 팀/조직 특성 기반 커스터마이징

- 일하는 방식 (속도 vs 안정)
- 의사결정 구조
- 커뮤니케이션 방식

→ 동일한 역량이라도 평가 기준이 달라짐

---

## 5. 평가 기준 (공통)

| 점수 | 기준 |
|-----|------|
| 5 | 주도적 실행 + 명확한 성과 |
| 4 | 책임 수행 + 개선 경험 |
| 3 | 기본 수행 가능 |
| 2 | 반복 문제 |
| 1 | 책임 회피 |
