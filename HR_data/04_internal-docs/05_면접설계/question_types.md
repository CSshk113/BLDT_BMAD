# 질문 유형별 작성 규칙 (Question Types)

## 세 가지 질문 유형

구조화 면접은 세 가지 질문 유형을 혼합하여 역량을 다각도로 검증한다.

---

## 1. 행동 면접 질문 (BEI: Behavioral Event Interview)

### 원칙
- **과거 행동이 미래 행동을 예측한다**는 전제에 기반
- 실제로 경험한 구체적인 사례를 요청 → STAR 형식으로 답변 유도
- 가장 신뢰도가 높은 질문 유형

### STAR 구조
- **S**ituation: 어떤 상황/맥락이었나?
- **T**ask: 본인의 역할/책임은 무엇이었나?
- **A**ction: 구체적으로 어떤 행동을 했나?
- **R**esult: 결과는 어땠나? 배운 점은?

### 질문 작성 규칙
- "말씀해 주세요", "있었나요?", "경험이 있으신가요?" 형식으로 작성
- 구체적 사례를 요청하는 표현 포함: "가장 기억에 남는", "최근에", "가장 어려웠던"
- 복합 질문 금지 (하나의 질문에 하나의 역량만)

### 예시
```
✅ 좋은 예:
"여러 이해관계자의 의견이 충돌하는 상황에서 결정을 내려야 했던 경험을 말씀해 주세요.
어떤 방식으로 갈등을 조율했고, 결과는 어떠했나요?"

❌ 나쁜 예:
"협업을 잘 하시나요?" (행동 사례 없음, 예/아니오로 답변 가능)
"팀 프로젝트와 개인 작업 중 무엇을 더 선호하시나요?" (선호 묻기, 역량 검증 불가)
```

### Follow-up 탐침 질문 (Probing)
답변이 모호하거나 구체성이 부족할 때 사용:
- "그 상황에서 본인이 직접 하신 행동은 무엇인가요?"
- "결과적으로 어떻게 됐나요?"
- "그 경험에서 무엇을 배우셨나요?"
- "지금 같은 상황이 다시 생긴다면 다르게 하실 건 있나요?"

## 2. 상황 판단 질문 (SJT: Situational Judgment)

### 원칙
- **미래 상황에서 어떻게 행동할지**를 묻는 가상 시나리오 기반
- 실제 경험이 없는 역량이나 포지션 특화 판단력을 검증할 때 유용
- BEI보다 예측력은 낮으나 신규 경험이 없는 경우 보완적으로 활용

### 질문 작성 규칙
- "어떻게 하시겠습니까?", "어떻게 접근하시겠습니까?" 형식
- 현실적이고 직무와 직접 관련된 시나리오 사용
- 정답이 하나가 아닌 열린 상황을 설정 → 사고 과정을 관찰

### 예시
```
✅ 좋은 예:
"출시 D-3일에 핵심 기능에서 치명적인 버그가 발견되었습니다.
수정하면 일정이 2주 연기되고, 그냥 출시하면 일부 사용자에게 영향이 갑니다.
이 상황에서 어떻게 판단하고 행동하시겠습니까?"

❌ 나쁜 예:
"리더라면 어떻게 해야 한다고 생각하시나요?" (가치관 묻기, 실제 판단 검증 어려움)
```

### Follow-up 탐침 질문
- "그렇게 판단하신 이유는 무엇인가요?"
- "다른 선택지는 없었나요?"
- "그 결정에서 가장 중요하게 고려한 것은?"

## 3. 기술/지식 검증 질문 (Knowledge/Technical)

### 원칙
- 직군 수행에 필요한 **핵심 개념과 원리를 이해하는지** 확인
- 암기 여부가 아닌 적용·판단 능력을 보는 것이 목적
- 직군 특화 역량 검증에 주로 사용

### 질문 작성 규칙
- "설명해 주세요", "차이를 말씀해 주세요", "어떤 경우에 사용하시나요?" 형식
- 교과서적 답변보다 실무 맥락의 이해를 확인
- 너무 좁거나 트리비아(trivia)성 질문 금지

### 예시
```
✅ 좋은 예:
"REST API와 GraphQL의 주요 차이점과, 각각이 더 적합한 상황을 설명해 주세요."

"A/B 테스트를 설계할 때 통계적으로 유의미한 결과를 얻기 위해 고려해야 할 요소를 말씀해 주세요."

❌ 나쁜 예:
"HTTP 상태코드 404는 무슨 뜻인가요?" (너무 단순, 역량 검증 불가)
```

### Follow-up 탐침 질문
- "실제로 적용해 보신 적 있으신가요?"
- "그 방식의 단점은 무엇이라고 생각하시나요?"
- "더 좋은 대안이 있다고 생각하시나요?"

## 질문 유형 혼합 가이드

| 역량 | 권장 유형 비율 |
|------|--------------|
| 공통 역량 (문제해결, 협업 등) | BEI 60% + SJT 40% |
| 직군 기술 역량 | 기술/지식 40% + BEI 40% + SJT 20% |
| 리더십 역량 | BEI 50% + SJT 40% + 기술/지식 10% |

**역량당 질문 수**: 5~10개 (질문 은행 기준), 면접 당일 2~3개 선별 사용

---

## 금지 질문 목록

채용 차별 소지가 있는 질문은 절대 포함하지 않는다:

- 나이, 생년월일
- 결혼 여부, 자녀 계획
- 종교, 정치적 견해
- 출신 지역, 학교 (역량과 무관한 경우)
- 장애 여부, 건강 상태 (직무 수행과 직접 관련 없는 경우)
- 가족 관계, 재정 상황
